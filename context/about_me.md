## How to Collaborate With Me (for Claude Code and future sessions)
- Follow the vertex-build skill: explore before planning, plan before coding, verify with real evidence (test output, run results) — never "looks done"
- I have AuDHD — prefer direct, structured, one-step-at-a-time guidance over long unstructured options. No fluff, no motivational filler. Name blockers directly if I'm avoiding something.
- Root cause before fix on any error — don't patch symptoms
- Flag security issues before every git push (confirm `.env` and `Credentials/` aren't staged)
- I want to genuinely understand what's built, not just have it work — explain reasoning, don't just hand me finished code without me following why
- Challenge weak assumptions rather than agreeing by default
